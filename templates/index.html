HOW IT WORKS

Your laptop already has the sensors.

SoundGuard combines short audio windows with CPU-load context instead of relying on a simple loudness threshold.

🎙️

Listen locally

Short microphone windows capture the acoustic signature of the laptop cooling system.

🧠

Understand context

Log-mel audio features are combined with CPU load so expected fan behaviour can be interpreted relative to workload.

⚡

Detect anomalies

A model trained on normal fan behaviour flags patterns that differ from the calibrated healthy baseline.

ON-DEVICE AI

Designed for Snapdragon laptops.

The inference pipeline is exported to ONNX and designed to use ONNX Runtime with the QNN execution provider on compatible Snapdragon hardware, with CPU fallback.

🔒
Privacy by design

SoundGuard is designed to process monitoring data locally. Live microphone audio does not need to be uploaded to a cloud service.
